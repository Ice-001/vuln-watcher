## S2-078

- **CVE编号:** CVE-2026-104714
- **危害定级:** 中危
- **漏洞标签:** Disclosure of Data, Denial of Service
- **披露日期:** 
- **信息来源:** [https://cwiki.apache.org/confluence/spaces/WW/pages/451972217/S2-078](https://cwiki.apache.org/confluence/spaces/WW/pages/451972217/S2-078)

### 漏洞描述

Struts renders localized messages through an application-wide text provider, which retains the formatter used to render each message. Where a message formats a date or time argument, that retained formatter is used by requests being served concurrently without isolation between them, so two requests rendering the same message at the same time can interfere: a value belonging to one user can appear in another user's response, or the rendering can fail and surface as a server error. Triggering this requires no malicious request — ordinary concurrent traffic is enough, and the users harmed are the application's own.

### 修复方案

Upgrade to Struts 7.4.0 at least.

## MLflow Scorer 组件反序列化漏洞(CVE-2026-116692)

- **CVE编号:** CVE-2026-116692
- **危害定级:** 严重
- **漏洞标签:** 反序列化, 关键漏洞, 重点漏洞, 远程代码执行, POC公开
- **披露日期:** 2026-10-28
- **推送原因:** 漏洞创建
- **信息来源:** [https://ti.qianxin.com/vulnerability/detail/529412](https://ti.qianxin.com/vulnerability/detail/529412)

### 漏洞描述

MLflow 是一个开源的 AI 工程平台，旨在支持智能体、大语言模型和机器学习模型的开发、训练、部署和监控。它提供了实验跟踪、模型注册表、评估和部署等功能，帮助数据科学家和工程师管理机器学习生命周期。在 MLflow 3.12.0rc0 至 3.17.0 版本中，mlflow/genai/scorers/base.py 中的第三方评分器反序列化机制存在缺陷。该机制接受请求选择的 THIRD_PARTY_SCORER_ALLOWED_MODULES 的子模块，而不是要求精确匹配允许的模块。攻击者可以利用 MLflow 工件端点将 Python 模块放置在可写的允许包下，并通过 /ajax-api/3.0/mlflow/scorer/invoke 提交该模块和类。Scorer.model_validate_json() 在跟踪处理之前导入模块并构造类，从而导致任意代码执行。

## Progress WS_FTP Server 管理接口授权不当漏洞(CVE-2026-90863)

- **CVE编号:** CVE-2026-90863
- **危害定级:** 严重
- **漏洞标签:** 授权不当, 命令执行, 关键漏洞, 远程攻击, 重点漏洞, 权限提升, 授权缺失, 影响十万级
- **披露日期:** 2026-10-30
- **推送原因:** 漏洞创建
- **信息来源:** [https://ti.qianxin.com/vulnerability/detail/529329](https://ti.qianxin.com/vulnerability/detail/529329)

### 漏洞描述

- **漏洞标签:** POC已公开

## NGINX ngx_http_rewrite_module 堆缓冲区溢出漏洞 (CVE-2026-42945)

- **CVE编号:** CVE-2026-42945
- **危害定级:** 高危
- **漏洞标签:** POC已公开
- **披露日期:** 2026-05-14
- **信息来源:** [https://avd.aliyun.com/detail?id=AVD-2026-42945](https://avd.aliyun.com/detail?id=AVD-2026-42945)

### 漏洞描述

NGINX Plus 和 NGINX Open Source 的 ngx_http_rewrite_module 存在堆缓冲区溢出漏洞。该漏洞在特定配置下触发：rewrite 指令的替换字符串包含问号 ?，并且后续跟随 rewrite、if 或 set 指令，同时使用未命名 PCRE 捕获组（如 $1、$2）。远程未认证攻击者可通过构造恶意 HTTP 请求触发该缺陷，导致 NGINX worker 进程发生堆内存破坏并重启，造成拒绝服务；在关闭 ASLR 的系统上，可能进一步实现远程代码执行。

### 修复方案

1. 升级Nginx至最新版本。
2. 使用 NGINX Plus. NGINX Ingress Controller. NGINX Gateway Fabric. F5 WAF/App Protect 等相关产品的环境，应按 F5 官方公告升级到对应修复版本。
3. 通过操作系统包管理器安装的Nginx其安全版本由上游操作系统发行方决定。
